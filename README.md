# Codex Skills

Reusable Codex skills for practical, outcome-focused work.

## Included skills

- `apply-mve-frontend` - Apply a reusable Minimum Viable Experience framework to frontend design, review, implementation, and refinement.
- `design-ui-with-restraint` - Design or improve interfaces with clear structure, useful elements, accurate visuals, and polished interactions.
- `write-practical-copy` - Write or improve interface and product copy using clear, natural, practical language.

Skills live under [`skills/`](skills/). Each skill contains its required `SKILL.md` and any optional Codex metadata or resources.
